插件是你自己寫、自己用的小程式，讓你自己寫的組件做到 FullWidget 還做不到的事：讀取別的軟件的資料、控制硬件、調用本機的工具、跑一段 Python……用什麼語言寫都可以。

## 插件是什麼

一個插件就是插件資料夾裏的一個資料夾，裏面有：

- `plugin.json`：說明它叫什麼、怎樣啟動。
- 程式本身：一個腳本（`.py`、`.js`、`.ps1`、`.bat`）或一個 `.exe`，用什麼語言寫都可以。

FullWidget 把它當成一個獨立的程式運行（看不到視窗），用**標準輸入和標準輸出**和它溝通，一行一個 JSON：

```
組件  ──widget.plugin("obs").call("status")──▶  FullWidget  ──{"id":1,"method":"status"}──▶  插件
組件  ◀──────────── 結果 ─────────────────────  FullWidget  ◀──{"id":1,"result":{...}}──────  插件
組件  ◀──────── .on("changed", …) ────────────  FullWidget  ◀──{"event":"changed",...}──────  插件（隨時）
```

**什麼時候需要插件：**

| 想做的事 | 用什麼 |
|---|---|
| 從網上拿資料 | 不用插件：組件裏的 `widget.fetch`（`network:` 權限） |
| 偶爾跑一條命令、看它的輸出 | 不用插件：組件裏的 `widget.shell.run` 或 `widget.shell.exec`（`shell.run` 權限，見[組件開發指南](組件開發指南.md)） |
| 要一直開著、記住狀態、持續送資料（連著 OBS、監聽硬件、每秒讀感應器） | 插件 |
| 要用某種語言的套件（Python 的 `psutil`、Node 的某個 SDK） | 插件 |
| 一條命令很慢、每次啟動都要好幾秒 | 插件：啟動一次，之後每次呼叫都很快 |

**限制：** 只有你自己寫的組件能用你的插件。用「新建組件」建立的組件可以直接用；自己複製進組件目錄的，第一次要在控制中心「我的組件」裏允許它的權限。用了插件的組件不能打包成安裝包（.fwz），也不會上組件市場。

## 五分鐘試一個

1. 控制中心 →「設定」→「插件」→「新建插件」，名稱填 `hello`。FullWidget 會建立一個能運行的 PowerShell 插件、打開它的資料夾，並且直接允許它。
2. 控制中心 →「添加組件」→「新建組件」，建立一個組件。
3. 在組件的 `widget.json` 的 `permissions` 加上 `"plugin:hello"`：

```json
"permissions": ["plugin:hello"]
```

4. 在組件的 `main.js` 裏：

```js
const hello = widget.plugin("hello");
document.body.textContent = await hello.call("hello", { name: "小明" });
hello.on("tick", (d) => console.log("插件說現在是", d.time));
```

組件上會出現「你好，小明！現在是 …」。範例插件的 `main.ps1` 有註解，可以從它改起。

## 資料夾和 plugin.json

插件資料夾在資料位置裏的 `plugins`，一般是 `%AppData%\FullWidget\plugins`（控制中心「設定 → 插件 → 打開資料夾」可以直接打開）：

```
plugins\
  obs\                 資料夾名稱就是插件名稱
    plugin.json
    main.py
    requirements.txt   （隨你：插件自己需要的其他檔案）
```

**插件名稱**（資料夾名稱）：英文字母、數字、`.`、`_`、`-`，以字母或數字開頭，最長 64 個字元，不分大小寫。`fullwidget.` 開頭的名稱留給[官方插件](#官方插件)。

**plugin.json：**

```json
{
  "name": "OBS",
  "description": "讀取 OBS 的直播和錄影狀態，也可以開始和停止。",
  "run": "main.py",
  "idleMinutes": 5
}
```

| 欄位 | 必填 | 說明 |
|---|---|---|
| `run` | 是 | 怎樣啟動它。見下面 |
| `name` | 否 | 顯示在控制中心的名稱，預設是資料夾名稱。可以寫成 `{"zh-TW": "…", "zh-CN": "…", "en": "…"}` |
| `description` | 否 | 一句話說明它做什麼，顯示在控制中心。也可以分語言 |
| `idleMinutes` | 否 | 沒有組件在用多少分鐘後讓它停下，預設 `5`；`0` 表示一直開著，直到 FullWidget 結束。最大 1440 |
| `version` | 否 | 版本號，例如 `"1.0.0"`，顯示在控制中心 |

檔案用 UTF-8 存，可以有 BOM、`//` 註解和結尾多餘的逗號。

**`run` 怎麼寫：** 在插件資料夾裏執行。

| 寫法 | 實際執行 |
|---|---|
| `"main.py"` | `python main.py`（要裝好 Python，`python` 在 PATH 裏） |
| `"main.js"` 或 `"main.mjs"` | `node main.js`（要裝好 Node.js） |
| `"main.ps1"` | `powershell.exe -NoProfile -NonInteractive -ExecutionPolicy Bypass -File main.ps1`（Windows 自帶的 PowerShell 5.1） |
| `"main.bat"` 或 `"main.cmd"` | `cmd.exe /d /s /c main.bat` |
| `"bin\\tool.exe --port 4455"` | 直接執行這個程式，後面是參數 |
| `"python -u main.py --verbose"` | 直接寫完整的命令也可以 |
| `"\"C:\\Program Files\\My Tool\\tool.exe\" --serve"` | 有空格的路徑用引號包起來 |
| `"pwsh -NoProfile -File main.ps1"` | 用 PowerShell 7 |
| `".venv\\Scripts\\python.exe main.py"` | 用插件資料夾裏的 Python 虛擬環境 |

**改了 plugin.json 要再允許一次。** FullWidget 記住的是 plugin.json 的內容，內容一變（多一個空格也算），插件就變回「等你允許」。改程式本身不用。

## 溝通協定

所有訊息都是**一行一個 JSON 物件**，UTF-8 編碼，以換行結束。JSON 裏不能有換行（字串裏的換行要寫成 `\n`，一般的 JSON 函式庫預設就是這樣）。

### FullWidget 送給插件（標準輸入）

```json
{"id": 1, "method": "hello", "params": {"name": "小明"}, "widget": "user.my-widget", "instance": "a1b2c3"}
```

| 欄位 | 說明 |
|---|---|
| `id` | 整數，這次請求的編號。回答時原樣帶回 |
| `method` | 字串，組件 `call` 的第一個參數 |
| `params` | 組件 `call` 的第二個參數，任何 JSON 值；沒傳時是 `null` |
| `widget` | 呼叫它的組件的 id（`widget.json` 的 `id`） |
| `instance` | 桌面上是哪一個（同一個組件放了兩個時不同） |

### 插件回答（標準輸出）

成功：

```json
{"id": 1, "result": "你好，小明"}
```

`result` 可以是任何 JSON 值（字串、數字、物件、陣列、`null`）。組件的 `await plugin.call(...)` 拿到的就是它。

失敗：

```json
{"id": 1, "error": "找不到 OBS，請確認 OBS 已經打開"}
```

`error` 寫一句給人看的話，組件那邊的 promise 會失敗，`e.message` 就是這句話。也可以寫 `{"message": "…"}` 物件。

- 每個請求都要回答一次，而且只回答一次。沒回答的話，組件等到逾時（預設 30 秒）會收到失敗。
- 可以不照順序回答：FullWidget 可能在你回答前就送來下一個請求。慢的工作放到另一個執行緒或非同步做，先處理後面的請求也可以。
- 回答了不存在的 `id`（例如已經逾時的），FullWidget 會忽略。

### 插件主動送事件（標準輸出）

```json
{"event": "changed", "data": {"streaming": true, "seconds": 125}}
```

任何時候都可以送，不用等請求。所有正在 `.on()` 聽這個插件的組件都會收到；沒有組件在聽時，事件直接丟掉。`event` 是字串，`data` 是任何 JSON 值。

### 規則

- **標準輸出只能寫上面這三種 JSON 行。** 任何其他輸出（`print("debug")`、進度條、套件印的警告）都會讓 FullWidget 在日誌裏警告，並被忽略。給自己看的訊息寫到**標準錯誤**（stderr），會記進 `app.log`，前面標著 `[plugin 名稱]`。
- **每寫一行都要 flush**，不然資料留在緩衝區，FullWidget 收不到：
  - Python：`print(..., flush=True)`（FullWidget 已經設好 `PYTHONUNBUFFERED=1`）。
  - Node.js：`process.stdout.write(json + "\n")` 會直接送出。
  - C#：`Console.Out.Flush()`，或開頭設 `Console.Out` 為 `AutoFlush`。
  - PowerShell：`[Console]::Out.WriteLine(...)` 後 `[Console]::Out.Flush()`。
- **編碼一律 UTF-8**，沒有 BOM。FullWidget 為 Python 設好了 `PYTHONUTF8=1` 和 `PYTHONIOENCODING=utf-8`。C# 和 PowerShell 要自己設輸出編碼（見範例）。
- 多個執行緒都會寫標準輸出時，要加鎖，一次寫完整的一行，不然兩行會混在一起。
- **標準輸入被關掉**（讀到檔案結尾）表示 FullWidget 要你結束：收尾，然後退出。3 秒內沒退出會被強制結束。

### 環境變數

| 變數 | 內容 |
|---|---|
| `FULLWIDGET_PLUGIN` | 插件名稱 |
| `FULLWIDGET_VERSION` | FullWidget 的版本，例如 `1.4.0` |
| `FULLWIDGET_LANG` | 介面語言：`zh-TW`、`zh-CN` 或 `en`，回錯誤訊息時可以用 |

工作目錄是插件資料夾，讀寫自己的設定檔用相對路徑就可以。

## 什麼時候運行

- **第一次用到時啟動。** 組件第一次 `call` 或 `on` 這個插件時，FullWidget 才啟動它。之後所有組件共用同一個程式。
- **沒人用就停下。** 沒有組件在 `on` 聽它、也沒有請求在等，`idleMinutes` 分鐘後 FullWidget 關掉它的標準輸入，讓它結束。下次用到再啟動。要一直開著，寫 `"idleMinutes": 0`。
- **自己結束了會重開。** 插件自己退出（出錯、崩潰）時，如果還有組件在聽它的事件，FullWidget 會等 1、5、15、30 秒後再啟動它。正在等回答的請求會馬上失敗。
- **一直崩潰就停下。** 3 分鐘內停了 5 次，FullWidget 不再重開，控制中心顯示「一直停下來，已經停止」和最後的錯誤。修好後在「設定 → 插件」按「重新啟動」。
- **存檔就重開。** 插件資料夾裏的檔案改了，運行中的插件會自動重新啟動，改程式不用自己重開。
- **跟著 FullWidget 結束。** FullWidget 結束時，插件和插件啟動的所有程式都會一起結束，不會留在背景。

所以插件啟動時要快、不要等使用者輸入，有狀態要自己存到檔案裏（重開後讀回來）。

## 在組件裏使用

**1. 聲明權限。** 在組件的 `widget.json`：

```json
"permissions": ["plugin:obs"]
```

用幾個插件就寫幾個 `plugin:名稱`。

**2. 呼叫方法：**

```js
const obs = widget.plugin("obs");

try {
  const s = await obs.call("status");                       // 等插件回 result
  render(s);
} catch (e) {
  show(e.message);                                          // 插件回的 error，或插件不能用的原因
}

await obs.call("start", { scene: "Live" });                 // 第二個參數就是插件收到的 params
await obs.call("export", null, { timeout: 120_000 });       // 慢的工作：等最多 120 秒（預設 30 秒，最長 10 分鐘）
```

**3. 聽事件：**

```js
const off = obs.on("changed", (data) => render(data));     // 插件送 {"event":"changed","data":…}
obs.on("*", (data, event) => console.log(event, data));    // "*" 收全部事件
off();                                                      // 不再聽
```

- `on` 會讓插件啟動（如果還沒運行），並讓它在你聽的期間一直開著。
- 組件關掉或重新載入時，FullWidget 會自動停止它的監聽，不用自己 `off()`。
- 插件重新啟動之後，事件會自動繼續送來，不用重新 `on`。但插件重開後的狀態要靠你自己再拿一次：常見做法是插件啟動時先送一次完整狀態的事件，或組件定時 `call` 一次。

**4. 處理插件不能用的情況。** `call` 失敗的原因可能是插件還沒允許、還沒裝、一直崩潰。把 `e.message` 顯示在組件上，使用者就知道要去哪裏處理。常見訊息見[常見錯誤](#常見錯誤)。

TypeScript 類型在 `sdk/widget.d.ts`：

```ts
interface Plugin {
  readonly name: string;
  call<T = any>(method: string, params?: any, options?: { timeout?: number }): Promise<T>;
  on(event: string, listener: (data: any, event: string) => void): () => void;
}
```

## 完整範例

下面四個插件做的事完全一樣，選你熟悉的語言：

- 方法 `hello`：參數 `{"name": "小明"}`，回 `"你好，小明"`。
- 方法 `add`：參數 `{"a": 1, "b": 2}`，回 `3`。
- 方法 `slow`：等 3 秒再回 `"done"`，示範慢的工作不會卡住其他請求。
- 其他方法回錯誤。
- 每 5 秒送一次事件 `tick`：`{"time": "14:03:05"}`。

每個範例都可以直接存檔使用，和這個組件搭配：

**組件 `widget.json`**（`permissions` 這一行是重點）：

```json
{
  "id": "user.plugin-demo",
  "name": "插件示範",
  "version": "1.0.0",
  "entry": "index.html",
  "size": { "width": 260, "height": 140 },
  "permissions": ["plugin:demo"]
}
```

**組件 `index.html`**（`widget` 物件和基本樣式由 FullWidget 自動加上，不用引入）：

```html
<!doctype html>
<html>
<head>
  <meta charset="utf-8">
</head>
<body>
  <div id="hello" class="w-title">…</div>
  <div id="tick" class="w-label">等插件的第一個 tick</div>
  <script src="main.js"></script>
</body>
</html>
```

**組件 `main.js`：**

```js
const demo = widget.plugin("demo");
const $ = (id) => document.getElementById(id);

try {
  $("hello").textContent = await demo.call("hello", { name: "小明" });
  console.log("1 + 2 =", await demo.call("add", { a: 1, b: 2 }));
} catch (e) {
  $("hello").textContent = "插件不能用：" + e.message;
}

demo.on("tick", (d) => { $("tick").textContent = "插件時間 " + d.time; });
```

### Python

資料夾 `plugins\demo\`。要先裝 [Python 3](https://www.python.org/downloads/)（安裝時勾選「Add python.exe to PATH」）。

`plugin.json`：

```json
{ "name": "示範（Python）", "run": "main.py" }
```

`main.py`：

```python
import json, sys, threading, time

lock = threading.Lock()

def send(obj):
    """寫一行 JSON 到 stdout。多個執行緒都會寫，所以加鎖。"""
    line = json.dumps(obj, ensure_ascii=False)
    with lock:
        sys.stdout.write(line + "\n")
        sys.stdout.flush()

def log(*args):
    """給自己看的訊息：寫到 stderr，會出現在 FullWidget 的 app.log。"""
    print(*args, file=sys.stderr, flush=True)

def slow(params):
    time.sleep(3)
    return "done"

METHODS = {
    "hello": lambda p: f"你好，{p['name']}",
    "add": lambda p: p["a"] + p["b"],
    "slow": slow,
}

def handle(req):
    try:
        fn = METHODS.get(req.get("method"))
        if fn is None:
            send({"id": req["id"], "error": f"沒有方法 {req.get('method')}"})
            return
        send({"id": req["id"], "result": fn(req.get("params") or {})})
    except Exception as e:
        send({"id": req.get("id"), "error": f"{type(e).__name__}: {e}"})

def ticker():
    while True:
        time.sleep(5)
        send({"event": "tick", "data": {"time": time.strftime("%H:%M:%S")}})

log("started")
threading.Thread(target=ticker, daemon=True).start()
for line in sys.stdin:                      # 讀到結尾：FullWidget 要我們結束
    if not line.strip():
        continue
    req = json.loads(line)
    # 每個請求一個執行緒：慢的 slow 不會卡住後面的請求
    threading.Thread(target=handle, args=(req,), daemon=True).start()
log("stopping")
```

要用第三方套件時，在插件資料夾開終端機執行 `python -m pip install 套件名稱`；想和別的 Python 專案分開，就建一個虛擬環境（`python -m venv .venv`，再 `.venv\Scripts\pip install 套件名稱`），`run` 寫 `".venv\\Scripts\\python.exe main.py"`。

### Node.js

資料夾 `plugins\demo\`。要先裝 [Node.js](https://nodejs.org/)。

`plugin.json`：

```json
{ "name": "示範（Node.js）", "run": "main.js" }
```

`main.js`：

```js
const readline = require("node:readline");

const send = (obj) => process.stdout.write(JSON.stringify(obj) + "\n");
const log = (...args) => console.error(...args);   // stderr → FullWidget 的 app.log

const methods = {
  hello: (p) => `你好，${p.name}`,
  add: (p) => p.a + p.b,
  slow: () => new Promise((r) => setTimeout(() => r("done"), 3000)),
};

async function handle(req) {
  const fn = methods[req.method];
  if (!fn) return send({ id: req.id, error: `沒有方法 ${req.method}` });
  try {
    send({ id: req.id, result: await fn(req.params || {}) });
  } catch (e) {
    send({ id: req.id, error: String(e && e.message || e) });
  }
}

log("started");
const timer = setInterval(() => send({ event: "tick", data: { time: new Date().toTimeString().slice(0, 8) } }), 5000);

const rl = readline.createInterface({ input: process.stdin });
rl.on("line", (line) => { if (line.trim()) handle(JSON.parse(line)); });   // 不 await：請求可以同時處理
rl.on("close", () => { log("stopping"); clearInterval(timer); process.exit(0); });   // stdin 關了：結束
```

`console.log` 會寫到 stdout，在插件裏不要用它來除錯，用 `console.error`。要用 npm 套件，在插件資料夾執行 `npm install 套件名稱`，`node_modules` 放在插件資料夾裏就可以。

### PowerShell

不用另外安裝，Windows 自帶。資料夾 `plugins\demo\`。檔案存成 **UTF-8 with BOM**（不然中文會亂碼；記事本「另存新檔 → 編碼：UTF-8 with BOM」）。

`plugin.json`：

```json
{ "name": "示範（PowerShell）", "run": "main.ps1" }
```

`main.ps1`：

```powershell
[Console]::OutputEncoding = New-Object Text.UTF8Encoding $false

function Send($obj) {
  [Console]::Out.WriteLine(($obj | ConvertTo-Json -Compress -Depth 10))
  [Console]::Out.Flush()
}
function Log($text) { [Console]::Error.WriteLine($text) }   # stderr → app.log

$methods = @{
  hello = { param($p) "你好，$($p.name)" }
  add   = { param($p) $p.a + $p.b }
  slow  = { param($p) Start-Sleep -Seconds 3; "done" }
}

function Answer($text) {
  $req = $null
  try {
    $req = $text | ConvertFrom-Json
    $m = $methods[$req.method]
    if (-not $m) { Send @{ id = $req.id; error = "沒有方法 $($req.method)" }; return }
    Send @{ id = $req.id; result = (& $m $req.params) }
  } catch {
    Send @{ id = $(if ($req) { $req.id } else { $null }); error = $_.Exception.Message }
  }
}

Log "started"
# 用 OpenStandardInput 讀：Windows PowerShell 5.1 的 [Console]::In 在等輸入時會卡住整個程式
$reader = New-Object IO.StreamReader([Console]::OpenStandardInput(), (New-Object Text.UTF8Encoding $false))
$next = $reader.ReadLineAsync()
$lastTick = Get-Date
while ($true) {
  if (-not $next.Wait(500)) {
    if (((Get-Date) - $lastTick).TotalSeconds -ge 5) {
      $lastTick = Get-Date
      Send @{ event = "tick"; data = @{ time = (Get-Date -Format "HH:mm:ss") } }
    }
    continue
  }
  $text = $next.Result
  if ($null -eq $text) { break }          # stdin 關了：結束
  if ($text.Trim()) { Answer $text }
  $next = $reader.ReadLineAsync()
}
Log "stopping"
```

PowerShell 一次只做一件事：`slow` 的 3 秒裏，其他請求和 tick 都要等。工作很慢的話，用 Python、Node.js 或 C# 會比較好；或用 `Start-Job` 自己排程。

### C#

適合要用 Windows API、或想做成一個 `.exe` 的情況。要先裝 [.NET SDK](https://dotnet.microsoft.com/download)。

在任何地方建立專案（不要放在插件資料夾裏，不然每次建置都會觸發插件重新啟動）：

```bat
dotnet new console -n DemoPlugin
cd DemoPlugin
```

`Program.cs`：

```csharp
using System.Text;
using System.Text.Json;
using System.Text.Json.Nodes;

Console.OutputEncoding = new UTF8Encoding(false);
Console.InputEncoding = new UTF8Encoding(false);
var stdout = Console.Out;
var gate = new object();

void Send(JsonObject obj)
{
    string line = obj.ToJsonString();                 // 一行，沒有縮排
    lock (gate) { stdout.WriteLine(line); stdout.Flush(); }
}
void Log(string text) => Console.Error.WriteLine(text);   // stderr → app.log

async Task<JsonNode?> Run(string method, JsonNode? p) => method switch
{
    "hello" => $"你好，{(string?)p?["name"]}",
    "add" => (double)p!["a"]! + (double)p!["b"]!,
    "slow" => await Task.Delay(3000).ContinueWith(_ => (JsonNode?)"done"),
    _ => throw new InvalidOperationException($"沒有方法 {method}"),
};

async Task Handle(string text)
{
    JsonNode? id = null;
    try
    {
        var req = JsonNode.Parse(text)!.AsObject();
        id = req["id"]?.DeepClone();
        var result = await Run((string)req["method"]!, req["params"]);
        Send(new JsonObject { ["id"] = id, ["result"] = result });
    }
    catch (Exception e)
    {
        Send(new JsonObject { ["id"] = id, ["error"] = e.Message });
    }
}

Log("started");
using var timer = new Timer(_ => Send(new JsonObject
{
    ["event"] = "tick",
    ["data"] = new JsonObject { ["time"] = DateTime.Now.ToString("HH:mm:ss") },
}), null, 5000, 5000);

while (Console.ReadLine() is string line)             // null：stdin 關了，結束
    if (line.Trim().Length > 0) _ = Task.Run(() => Handle(line));   // 每次都是新的 line，不會被下一行蓋掉
Log("stopping");
```

建置成一個 `.exe`，放進插件資料夾：

```bat
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o "%AppData%\FullWidget\plugins\demo\bin"
```

`plugin.json`：

```json
{ "name": "示範（C#）", "run": "bin\\DemoPlugin.exe" }
```

`--self-contained false` 的 exe 很小，FullWidget 本身需要的 .NET 9 已經裝好；如果你的電腦用的是 FullWidget 的「免安裝完整版」，改成 `--self-contained true`。

## 除錯

**先在終端機裏單獨測試插件。** 在插件資料夾打開終端機，把一行請求送進去，看它回什麼：

```bat
echo {"id":1,"method":"hello","params":{"name":"test"}} | python main.py
```

```powershell
'{"id":1,"method":"hello","params":{"name":"test"}}' | node main.js
```

應該看到一行 `{"id":1,"result":"你好，test"}`。也可以直接執行 `python main.py`，自己貼 JSON 進去、按 Enter，看回答；按 Ctrl+Z 再 Enter（Windows）結束輸入，插件應該自己退出。

**看日誌。** `%LocalAppData%\FullWidget\logs\app.log` 裏有：

- `Plugin demo: started (main.py), pid 1234`：啟動了，用的是什麼命令。
- `[plugin demo] …`：插件寫到 stderr 的內容，包括 Python 的錯誤堆疊。
- `[plugin demo] wrote something that isn't a JSON line`：標準輸出寫了不是 JSON 的東西。
- `Plugin demo: exited on its own (exit code 1)`：插件自己結束了，往上找它的錯誤訊息。
- `Plugin demo: could not start "…"`：命令錯了，或 `python`、`node` 不在 PATH 裏。

**看控制中心。** 「設定 → 插件」每一行顯示狀態（運行中／沒在運行／等你允許／一直停下來）、哪些組件在用，和最後一次的錯誤。運行中的插件可以「重新啟動」或「停止」。

**看組件。** 在控制中心「設定」打開「開發者模式」，在組件上按 F12 打開開發者工具，`call` 失敗的訊息會出現在 Console。

## 安全和限制

- 插件用你的身份運行，能做你在這台電腦上能做的任何事。所以插件要在「設定 → 插件」裏**允許**之後才會運行，允許時會列出它要執行的命令；`plugin.json` 改過要再允許一次。
- 只有你自己寫的組件能用插件。安裝包（.fwz）和組件市場的組件都不能用你的插件（[官方插件](#官方插件)除外）；手動複製進來的組件，要你在「我的組件」裏允許。
- 插件不能放進安裝包（.fwz），組件市場也不收用插件的組件。要分享，就把插件資料夾和組件資料夾一起給對方，請對方自己放好、自己允許。
- 別人叫你把某個資料夾放進 `plugins` 時，先看清楚它在做什麼。

### 官方插件

組件市場有「官方插件」專欄，只放 FullWidget 自己做的插件，名稱都是 `fullwidget.` 開頭，原始碼在[組件市場的 plugins 資料夾](https://github.com/hmgvibe/fullwidget-market/tree/main/plugins)公開。在控制中心「添加組件 → 線上 → 官方插件」安裝，裝好就是允許的。任何組件（包括市場上的）都可以用官方插件，例如 `"plugin:fullwidget.perf"`。

| 官方插件 | 提供 |
|---|---|
| `fullwidget.perf` 性能數據 | 每秒的事件 `stats`：顯示卡使用率、顯存、溫度、功耗、時脈，和每個在繪製畫面的軟體的幀率。方法：`stats`、`info`、`enableFps`。見它的 [README](https://github.com/hmgvibe/fullwidget-market/tree/main/plugins/fullwidget.perf) |
| `fullwidget.files` 檔案 | 用戶用插件的視窗選了資料夾之後，列出裏面的檔案和圖示，打開、在檔案總管顯示、拖出去、把檔案放進來、改名、新增資料夾、刪到資源回收筒，有變化時送出事件 `changed`。只能碰用戶選的資料夾。見它的 [README](https://github.com/hmgvibe/fullwidget-market/tree/main/plugins/fullwidget.files) |

## 常見錯誤

組件裏 `call` 失敗時 `e.message` 的內容：

| 訊息 | 原因和做法 |
|---|---|
| `no plugin "demo" (looked for …\plugin.json)` | 插件資料夾裏沒有 `demo\plugin.json`。檢查資料夾名稱和位置 |
| `plugin "demo": plugin.json: …` | plugin.json 格式錯誤，或少了 `run` |
| `plugin "demo" hasn't been allowed yet` | 去「設定 → 插件」按「允許」 |
| `plugin "demo" could not start "…"` | `run` 的命令找不到：路徑錯了，或 Python／Node 沒裝、不在 PATH 裏 |
| `plugin "demo" didn't answer "hello" within 30 s` | 插件沒有回答：沒 flush、`id` 寫錯、卡住了，或工作真的太慢（用 `{ timeout }` 等久一點） |
| `plugin "demo" stopped (exit code 1)` | 插件在回答前結束了，看 `app.log` 裏它的錯誤 |
| `plugin "demo" kept stopping and was left stopped` | 3 分鐘內崩潰 5 次。修好後在「設定 → 插件」按「重新啟動」 |
| `plugin "demo" was stopped` | 你在控制中心按了「停止」，或插件被重新啟動 |
| `permission denied: add "plugin:demo" to permissions in widget.json` | `widget.json` 的 `permissions` 沒寫 `"plugin:demo"` |
| `permission "plugin:demo" is declared but the user has not allowed it yet` | 組件是手動複製進來的：在控制中心「我的組件 → 這個組件」允許它的權限 |
| `built-in widgets don't use "plugin:demo"` | FullWidget 內建的組件不能用插件，請用自己建立的組件 |
| 插件自己回的 `error` | 原樣傳過來，例如 `沒有方法 foo` |

## 寫完前檢查

給自己（或 AI）對照：

- [ ] 插件資料夾名稱就是組件裏 `widget.plugin("…")` 用的名稱，`widget.json` 有 `"plugin:名稱"` 權限。
- [ ] `plugin.json` 有 `run`，而且在插件資料夾裏執行這個命令能啟動它。
- [ ] 標準輸出只寫 JSON 行，每行 flush；除錯訊息寫 stderr。
- [ ] 每個請求都用同一個 `id` 回答一次，出錯時回 `error` 而不是讓程式崩潰。
- [ ] 慢的工作不會卡住其他請求（Python 用執行緒、Node 用 async、C# 用 Task）。
- [ ] 讀到標準輸入結尾就結束。
- [ ] 輸入輸出都是 UTF-8，中文不會亂碼。
- [ ] 在終端機用 `echo {...} | 命令` 測過，回答正確。
- [ ] 組件處理了 `call` 失敗的情況，把 `e.message` 顯示出來。
