# 官網 — 說明

日期：2026-11-03

## 結果

做了 FullWidget 的官網，原始碼在 `site/`，三種語言（繁中、簡中、英文），桌面和手機都能看。已上線：<https://hmgvibe.github.io/FullWidget/>（2026-11-03 開啟 GitHub Pages，來源是 GitHub Actions）。

本機預覽：

```
node site/build.mjs
```

會產生 `_site/`，用任何靜態伺服器打開 `_site/index.html`。`_site/` 不進 git。

## 頁面

2026-11-15 按三個賣點重新編排：**開箱即用、高度自定義、高擴展性**。

1. **首屏**：
   - 大標「一個不一樣的 Windows 桌面小組件」，副標「裝好就有 38 個組件。外觀隨你改，功能隨你加。」，旁邊是下載鍵。
   - 下面是 38 個組件的瀑布流，每個組件放在一小塊自己的桌布上，各欄慢慢往下流；滑鼠移上去會暫停，也有「暫停」按鈕。
   - 瀑布流下面一排三個賣點（01 開箱即用、02 高度自定義、03 高擴展性），點了跳到對應的段落。
2. **01 開箱即用**：
   - 一張桌面場景，用 1、2、3 標出三步：執行 setup.exe 安裝 → 桌面上出現組件 → 打開控制中心添加更多。
   - 接着是全部 38 個組件：預覽圖、名稱和一句說明（取自各組件的 `widget.json`），可以按分類篩選、切換三套主題。手機上先顯示 8 個，按「顯示全部 38 個」展開。
3. **02 高度自定義**：
   - 一個真的在跑的時鐘組件，往下捲時依次換主題、調外觀（強調色、圓角、透明度）、打出 CSS 並套用；往回捲會倒着變回去。手機上時鐘固定在上半部，下半部是這一步的說明。
   - 「擺放和行為」六項：每個組件有自己的設定（可以放好幾個各設各的）、靠近就對齊、拉大內容跟着變大、置頂或沉到桌面、卡片/毛玻璃/透明、鎖定和滑鼠穿透。
4. **03 高擴展性**（深色）：
   - 「一個組件，就是一個小網頁」：時鐘的 `widget.json`、`index.html`、`main.js` 三個分頁可以切換；提到開發文檔可以整份交給 AI。連到組件開發文檔。
   - 「接上任何程式」：執行 PowerShell/cmd、插件（任何語言），以官方插件「性能數據」為例，附兩段示範程式碼。連到插件開發文檔。
   - 「分享出去，或裝別人的」：.fwz、組件市場、更新提醒；旁邊是安裝第三方組件時的權限確認卡（用市場裏真的「護眼提醒」）。
   - 最下面「組件市場上現在有 N 個組件」：打開網頁時即時讀取組件市場的 `index.json`，先放其他作者的組件，最多 8 個。讀不到時整塊不顯示。
5. **開源・放心**：三點並排：沒有帳號、廣告、統計；GPL-3.0；記憶體用量。
6. **下載**：
   - 下載鍵連到 GitHub 最新 Release 頁。下面說明頁上三個檔案：setup.exe（推薦）、full.zip（免安裝，可放隨身碟）、精簡版 zip（要先裝 .NET 9）。
   - 附 SmartScreen 兩個畫面的示意圖，標出要按「其他資訊」和「仍要執行」。
7. **頁尾**：GitHub、開發文檔、隱私、GPL-3.0。

手機上按下載鍵會改成複製下載連結，並提示「這是 Windows 電腦軟件」。

## 怎麼做的

- **方向**：用 oil-ui 流程。
  - 先拆了 Seelen、Lively、Rainmeter、Raycast 的真實首屏，它們都是「深色底、居中標題、截圖」。這裏改用淺色頁面，讓組件自己的顏色當主角。
  - 第一版方向（可以拖動的桌面）你不要，改成現在的純介紹。
- **真的組件跑在網頁裏**：`site/widget-host.js` 在網頁裏扮演 FullWidget 主程式。時鐘的 HTML、CSS、JS 原封不動載入，主題、外觀和 CSS 的變化都走產品本身的接口。
- **組件圖片**：
  - `build/make-previews.mjs` 新增 `--scale 2 --out <資料夾>`，以 2 倍解析度重新渲染了全部 342 張（38 個組件 × 3 主題 × 3 語言），放在 `site/assets/widgets/`。
  - 渲染時組件放在螢幕外，不會在你的桌面上跳出來。
- **控制中心截圖**：`site/assets/app/`，三種語言，版本號 1.2.0。
- **動效庫**：Motion（MIT 授權，`site/vendor/`，自己託管）。沒用 GSAP，因為它的授權不是開源授權，會影響 SignPath 的申請。
- **不連第三方**：首頁不連任何第三方網站，字體用系統字體，動效庫也放在本站。
- **分享圖**：`site/assets/og.png`。
- **發佈流程**：`.github/workflows/site.yml`。改了 `site/`、組件或版本號，或發佈新 Release 時，自動重建並發佈到 GitHub Pages，網址會是 `https://hmgvibe.github.io/FullWidget/`。
